# Supabase Integration for Nuxt

> The client is initialized with the `NUXT_PUBLIC_SUPABASE_KEY` you must have in your `.env` file. It establishes the connection with the database and make use of user JWT to apply [RLS Policies](https://supabase.com/docs/learn/auth-deep-dive/auth-row-level-security){rel="&#x22;nofollow&#x22;"} implemented in Supabase. If you want to bypass policies, you can use the [serverSupabaseServiceRole](https://supabase.nuxtjs.org/services/serversupabaseservicerole).
